# RS3 Ultra: дизайн интерфейса

Задача — быстро выбрать чувствительность своей мыши. Это компактная утилита.

## План

- Фон `#F3F5F8`, рабочая поверхность `#FFFFFF`, графит `#202938`.
- Вторичный текст `#687487`, индиго `#5262D8`, разделители `#E3E7EE`.
- Segoe UI Variable / Segoe UI: 12, 14, 20, 26 px; число DPI — 42 px.
- Сетка 8 px; навигация 192 px; поля высотой 36–40 px.
- Выравнивание по левому краю, основной экран без прокрутки.

## Проверка плана

Шесть раскрытых столбцов отклонены: повторяют отвергнутый интерфейс и тратят
место на неактивные значения. Большая карточка модели и декоративная мышь
убраны. Отличительный элемент — редактор выбранной ступени с её цветом,
а не набор одинаковых карточек. Батарея занимает одну строку.

Основные сведения показываются сразу, справка — в подсказках. Цвет выбирается
пикером с палитрой и произвольным RGB. HEX остаётся внутри пикера как опция.
Редкие настройки сенсора — на соседней вкладке. Прокрутка вспомогательных
экранов — тонкая, без стрелок Windows.

Анимации здесь не реализуются. Рекомендации оформляются отдельно по навыку
finding-animation-opportunities и его четырём фильтрам.
